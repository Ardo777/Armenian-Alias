# Հայկական Ալիաս — Armenian Alias

Веб-игра «Алиас» на армянском языке. Открывается с телефонов по Wi-Fi, без установки приложений.

## Запуск

```bash
./mvnw spring-boot:run
```

При старте в консоли печатается адрес:

```
   Բառարան / словарь:  437 բառ
   На этом компьютере: http://localhost:8080
   С телефонов (Wi-Fi): http://192.168.0.169:8080
```

Все телефоны должны быть в той же Wi-Fi сети, что и компьютер. Второй адрес и нужно открыть
на телефонах (или отдать ссылку кнопкой «Պատճենել հղումը» в лобби).

> Если телефоны не подключаются — скорее всего, firewall macOS блокирует входящие соединения:
> *Системные настройки → Сеть → Файрвол* → разрешить входящие для `java`.

## Как играть

1. **Первый, кто открыл сайт**, нажимает «Ստեղծել խաղ» и становится **админом**. Он получает
   код комнаты из 4 символов.
2. Остальные вводят этот код и своё имя — и попадают в лобби.
3. Админ открывает «Կազմել թիմերը»:
   - распределяет игроков по командам (тап по игроку → тап по «+ Ավելացնել» у команды),
     либо жмёт «🎲 Խառնել բոլորին» для случайного распределения;
   - задаёт названия команд; логотип (эмодзи + градиент) генерируется случайно,
     тап по логотипу — перегенерировать;
   - на вкладке «Կանոններ» задаёт длительность раунда, **количество пропусков на раунд**,
     сложность слов, условие победы и штраф за ошибку.
4. Минимум **2 команды по 2 игрока** — иначе игра не начнётся.
5. В раунде один игрок объясняет слово, его команда угадывает. **Слово видно только
   на телефоне объясняющего**; под словом показан список однокоренных слов, которые
   произносить нельзя.
6. Три кнопки у объясняющего: зелёная ✓ (угадали, +1), серая ↷ (пропуск, тратит лимит),
   красная ✕ (не угадали, −1 при включённом штрафе).
7. После раунда — список сыгранных слов; тап по строке исправляет ошибочное нажатие.
8. Ход переходит следующей команде, объясняющий внутри команды меняется по кругу.

## Как это устроено

| Файл | Назначение |
|---|---|
| `game/Room.java` | Состояние комнаты и машина состояний партии |
| `game/RoomService.java` | Реестр комнат, сокеты, таймеры раунда |
| `game/WordBank.java` | Загрузка словаря, раздача перемешанной колоды |
| `ws/GameWebSocketHandler.java` | Протокол WebSocket, права админа/объясняющего |
| `resources/words.json` | 437 армянских слов с однокоренными запретами |
| `resources/static/` | Клиент: `index.html`, `styles.css`, `app.js` |

Состояние партии живёт на сервере; клиенты получают его по WebSocket. Текущее слово
отправляется **только** объясняющему — подсмотреть его с чужого телефона нельзя.
Таймер раунда тоже серверный, так что все устройства видят одно и то же время.

При обрыве связи (телефон заснул, ушёл в фон) клиент сам переподключается и возвращается
в свою комнату тем же игроком. Если отвалился админ, через 45 секунд права переходят
другому игроку, чтобы игра не зависла.

## Словарь

`src/main/resources/words.json` — массив записей:

```json
{ "word": "Դպրոց", "level": 1, "taboo": ["դպիր", "դպրոցական", "դպրոցահասակ"] }
```

`level`: 1 — лёгкое, 2 — среднее, 3 — сложное. `taboo` — однокоренные слова, которые
показываются объясняющему как запрещённые. Чтобы добавить слова, просто дополните файл
и перезапустите приложение.
